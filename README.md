# GoMate WhatsApp Bot 🚜

A WhatsApp chatbot for equipment rental in Maharashtra.

## Features
- Trilingual support (English, Marathi, Hindi)
- Customer flows: Search, book, check status
- Owner flows: List equipment, manage subscriptions via Razorpay
- AI Assistant powered by Google Gemini 2.5 Flash

## Tech Stack
Node.js, Express, Twilio, Supabase, Razorpay, Google GenAI

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and configure variables
3. Run `npm start`
